- **Usage accounting:** the cache hit ratio now counts cache writes as part of the prompt. `details.cache.hitRatio` is cache reads over fresh input, cache writes and cache reads together, where it left the writes out, so on Anthropic and Bedrock calls that write cache it drops to its true value: 100 fresh, 5,000 written and 5,000 read is 49.5%, where it was reported as 98%. Cost is unchanged for those adapters, which price each count at its own rate. A `cache-inclusive` adapter's input count is now read as holding every cached token, written as well as read, and membrane subtracts both; no built-in inclusive adapter reports cache writes, so no count they produce changes. The docs that gave the total prompt as `inputTokens + cacheReadTokens` now give `inputTokens + cacheCreationTokens + cacheReadTokens`.
