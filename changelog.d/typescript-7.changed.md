- **Build:** membrane is now built and typechecked with TypeScript 7 (`^7.0.2`), the native compiler, in place of 5.9. Built from the same source, the published JavaScript is byte-identical; 11 of the 57 declaration files differ, each only in the quote style of a string-literal type (`'wire-request'` for `"wire-request"`); and 46 of the 114 source maps (22 `.js.map`, 24 `.d.ts.map`) differ in their `mappings`, and in nothing else. A git or clone install runs the `prepare` build, which now needs TypeScript 7's compiler binary. That ships as optional packages for twenty OS/CPU pairs, so on another platform, or with optional dependencies omitted, the build fails, where 5.9's JavaScript compiler ran wherever Node does. A registry install runs no compiler.
