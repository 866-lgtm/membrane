- **Build:** membrane is now built and typechecked with TypeScript 7 (`^7.0.2`), the native compiler, in place of 5.9. Built from the same source, the published JavaScript is byte-identical; the declaration files that differ do so only in the quote style of string-literal types (`'wire-request'` for `"wire-request"`); and the source maps that differ do so only in their `mappings`. A git or clone install runs the `prepare` build, which now needs TypeScript 7's compiler binary. That ships as optional packages for twenty OS/CPU pairs, so on another platform, or with optional dependencies omitted, the build fails, where 5.9's JavaScript compiler ran wherever Node does. That build also needs Node 20.10 or later on the 20 line, since Node 20.0 to 20.9 refuses 7's launcher (`ERR_UNKNOWN_FILE_EXTENSION`). A registry install runs no compiler.
