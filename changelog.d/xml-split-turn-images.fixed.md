- In XML tool mode, a round whose tool result carries an image sends the image in a user turn of its own, and the response used to keep only the result's text, so a later request built from it showed no image and no sign of one. Now the result whose images were sent keeps what the tool returned, images included, in its block and in the response's tool results, and its block marks where the results block split (`rawXmlImagesAt`). The XML replay sends the block split there, with those images, as the turn did, so the model keeps seeing them on later turns, as in native tool mode. Later requests therefore carry those images until something removes them. A response stored before this fix replays as it did.
